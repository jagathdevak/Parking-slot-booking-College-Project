PARKORA PARKING GARAGE — XAMPP

1. Extract this folder to C:\xampp\htdocs\
2. Start Apache + MySQL in XAMPP.
3. Open http://localhost/Parkora_Parking_Garage/

Database parking_garage and tables are created automatically.

FEATURES
- Public parking directory + search
- Driver registration/login
- Driver dashboard
- Live available slots
- Start parking session
- Vehicle number/type capture
- One active session per driver
- Exit parking and automatic hourly charge
- Parking history
- Admin dashboard
- Occupancy + revenue stats
- Recent parking activity
- Admin can add new parking slots
- Responsive UI

Payment flow: Driver Login → Simulated Payment → Parking Slot Selection → Vehicle Details → Active Parking Session. The payment gateway is for demonstration only and does not process real money.
